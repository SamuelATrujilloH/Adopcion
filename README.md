# 🐾 Sistema de Gestión y Adopción para Refugio Animal

Plataforma web interactiva desarrollada para la visualización, solicitud y administración de adopciones en un refugio de animales. El sistema optimiza el proceso de adopción facilitando la interacción entre los adoptantes y el personal administrativo del refugio.

---

## 🚀 Funcionalidades Clave

### 👤 Módulo de Usuario (Vista Pública)
* **Catálogo de mascotas:** Consulta visual de los animales disponibles para adopción.
* **Detalle de mascotas:** Ficha técnica con información de cada animal (edad, tamaño, estado de salud y descripción).
* **Solicitud de adopción:** Formulario dinámico para postulate como adoptante responsable.

### 🛡️ Módulo Administrativo (Gestión Interna)
* **Gestión de mascotas (CRUD):** Registro, actualización y eliminación de nuevas mascotas en adopción.
* **Administración de solicitudes:** Panel para revisar, dar seguimiento, aprobar o rechazar las solicitudes recibidas.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3 (Diseño responsivo y personalizado)
- **Estructura:** Arquitectura basada en componentes web estáticos
